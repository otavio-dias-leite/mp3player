# Instalador web (planejado)

O instalador final será servido por HTTPS e usará Web Serial/WebUSB para gravar o binário compilado. Não publicar um botão de flash até que o artefato tenha sido compilado, testado em Cardputer-Adv e acompanhado de checksum e instruções de recuperação.

Para entrar no modo de gravação no dispositivo: desligue-o, mantenha G0 pressionado, ligue-o e solte G0. O navegador precisa de suporte à API usada e de permissão explícita do usuário.
